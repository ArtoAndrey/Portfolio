# Исследование факторов ценообразования недвижимости (Яндекс.Недвижимость)

Проект посвящён комплексному анализу данных (EDA) и факторному анализу стоимости жилой недвижимости в Санкт-Петербурге и Ленинградской области для построения автоматизированной системы оценки объектов.

## 🛠 Используемый стек технологий
* Python, Pandas, NumPy
* Matplotlib, Seaborn
* Phik (анализ нелинейных корреляций)

## 📊 Ключевые результаты и инсайты
1. Общий объём выборки сохранён на уровне 91.72% (потери <10%).
2. Доказано нелинейное влияние категории этажа на стоимость (Phik = 0.20).
3. Математически определена граница центра Санкт-Петербурга — 7 км.
