# Ride-Hailing Demand Forecasting (CatBoost + Optuna GPU)

Проект по краткосрочному прогнозированию спроса на заказы такси в районах аэропортов для оптимизации распределения автопарка Smart Mobility платформ.

## Ключевые этапы и результаты:
* **Анализ данных (EDA):** Проведена декомпозиция временного ряда на тренд и внутрисуточную сезонность. Стационарность ряда математически подтверждена тестом Дики-Фуллера ($p\text{-value} = 0.0289$).
* **Feature Engineering:** Развёрнута матрица признаков, включающая календарные маркеры, суточные лаги (24 часа) и скользящее среднее. Использован параметр `closed='left'` для 100% защиты от утечки данных (Data Leakage).
* **Моделирование и валидация:** Данные разделены строго по времени без перемешивания (10% на тест). Валидация моделей реализована через `TimeSeriesSplit` на 5 фолдах.
* **Оптимизация параметров:** Настроен автоматический подбор гиперпараметров `CatBoostRegressor` через фреймворк `Optuna` с аппаратным ускорением на GPU.
* **Итоговая метрика:** Финальное качество на отложенном тесте составило **RMSE = 41.82**, что значительно лучше жесткого бизнес-требования технического задания (RMSE $\le$ 48).
